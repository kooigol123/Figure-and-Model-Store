# Figure and Model Store

โปรเจควิชา 01418441-65 Web Technology and Web Services\
ระบบร้านค้าจำหน่ายโมเดลและฟิกเกอร์ออนไลน์ (E-Commerce Web Application)

---

## Tech Stack

* Backend: Node.js, Express.js, PostgreSQL
* Frontend: Vue 3, Vite, Pinia, Vue Router, Axios
* API Document: Swagger UI

---

## วิธีการรันโปรเจกต์ (เปิด 2 Terminal)

1. ฝั่งหลังบ้าน (Backend):
```bash
cd backend
npm run dev
```
* Backend API: http://localhost:3000/
* Swagger API Document: http://localhost:3000/api-docs

2. ฝั่งหน้าบ้าน (Frontend):
```bash
cd frontend
npm run dev
```
* หน้าเว็บ: http://localhost:5173/

*(ถ้าต้องการหยุดรัน ให้กด Ctrl + C ใน Terminal)*
